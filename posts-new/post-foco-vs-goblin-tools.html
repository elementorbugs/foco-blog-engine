Goblin Tools is the fastest way to break one overwhelming task into five small steps: free, no login, and gone the moment you close the tab. FOCO does the same breakdown, but stays with you while you work through the steps, with time estimates and soft check-ins.

Pick Goblin Tools when you need a breakdown in the next 15 seconds and nothing else. Pick FOCO when the breakdown alone hasn't been enough to get you actually moving.

  • FOCO breaks a task down the same way, then stays with you: time estimates per step, a timer, and soft check-ins while you work.
  • Both are built around task initiation, the ADHD gap between knowing what to do and starting it. Goblin Tools solves the "too big to start" half; FOCO also solves the "drifted off after step one" half.

What is Goblin Tools?

Goblin Tools is a free web app built around one job: breaking an overwhelming task into smaller pieces. The developer built it for their own ADHD partner, and it shows in the design choices.

The flagship feature is Magic ToDo. You type a task like "clean kitchen" or "write report," and it returns five small steps in seconds. Click any step to break it down further if it's still too big.

The interface is deliberately plain: no animations, no streaks, no gamification. Every visual flourish is a chance for an ADHD brain to get distracted, so Goblin Tools has almost none.

Beyond Magic ToDo, eight more single-purpose tools live on the site: Formalizer (rewrites text tone), Judge (emotional read of a message), Taskmaster (single-task focus), Estimator (time guesses), Compiler (organizes brainstorm dumps), and a few others. Most users only ever touch Magic ToDo.

What is FOCO?

FOCO is built for the same starting moment as Goblin Tools, then keeps going. You enter one stuck task, and FOCO breaks it into small first steps with time estimates.

The difference shows up after the breakdown. FOCO stays open with you, running a timer and offering soft check-ins as you move through each step, instead of handing you a list and stepping back.

That is the whole gap this comparison is about: a breakdown you look at once, versus a breakdown that stays present while you actually do the work. The National Institute of Mental Health notes that ADHD symptoms include difficulty sustaining attention on a task once started, which is exactly the second half neither a one-off list nor willpower reliably fixes on its own.

Which is better for starting a task right now?

For the pure moment of "I cannot start this," the two are close, and Goblin Tools has a slight edge on raw speed.

No login, no account, type and go. The Russell Barkley executive function model frames ADHD as weaker self-regulation, so for a brain where the setup itself can become the procrastination, that zero-friction path matters.

FOCO asks for slightly more, opening the app and entering the task, though it still has no configuration step and no methodology to choose. The gap in friction between the two is small.

Where they genuinely diverge is what happens 90 seconds later, once the list exists and the task is still sitting there.

Which one actually remembers what you're doing?

FOCO does. Goblin Tools does not, by design.

Close the Goblin Tools tab and the five steps are gone. There's no session, no history, no way to come back to where you left off. It solves the breakdown problem and stops there.

FOCO's steps come with time estimates and a running timer, and the app offers a soft check-in if you've drifted, rather than silently letting the tab go stale. For a task that takes longer than the five seconds it took to generate the list, that persistence is the difference between a plan and a completed task.

Neither approach is wrong. A task you'll finish in one sitting doesn't need memory. A task you'll drift away from at minute three does.

How do the free tiers compare?

Goblin Tools' free tier is the entire product. Magic ToDo, all nine tools, unlimited use, no account, no paywall on the web. The only paid option is a one-time ~$0.99 mobile app, purely for convenience.

FOCO's website tools (brain dump, focus timers, body doubling room) are free forever the same way. The breakdown app itself is $9/month or $59/year after a 7-day trial, since that's where the ongoing time estimates and check-ins live.

If cost alone decides it, Goblin Tools is the cheaper option outright for a one-off breakdown. The real question is whether a breakdown that disappears in 15 seconds solves your actual problem, or whether you need something to still be there in minute ten.

When should you pick Goblin Tools?

Pick Goblin Tools when any of these are true.

You need a breakdown in the next 15 seconds and nothing else. Open the page, type, done. No app to download, no account to make.

The task is short enough to finish in one sitting. If you'll be done in ten minutes, you don't need a tool that remembers you mid-task.

You've abandoned other apps during setup. Goblin Tools has none, which removes that specific failure point entirely.

When should you pick FOCO?

Pick FOCO when any of these are true.

Breaking the task down hasn't been the problem. You can list five steps fine. You still don't do step one, or you start and drift by step two.

The task takes longer than a few minutes. Time estimates and check-ins matter more the longer a task runs.

You want the app to notice if you've stalled, instead of silently sitting in a closed tab while the task stays undone.

FAQ

Is Goblin Tools really completely free?

The web version is fully free with no account required and no usage limit. The mobile app is a one-time ~$0.99 purchase, not a subscription. Verify current pricing on the official site before downloading.

Does Goblin Tools save my task breakdowns?

No. Each Magic ToDo breakdown lives only in your current browser tab. Close it and it's gone, with no history or account to recover it from.

Is FOCO better than Goblin Tools?

Neither is universally better. Goblin Tools wins on speed and zero setup for a one-off breakdown. FOCO wins if the breakdown alone hasn't gotten you moving, because it stays present with time estimates and check-ins.

Can I use FOCO and Goblin Tools together?

Yes. Some adults use Goblin Tools for a fast breakdown, then move into FOCO if the task turns out to need more than a list to actually finish. They don't integrate directly, but nothing about using both conflicts.

Does Goblin Tools have a focus timer?

Not really. The Taskmaster tool keeps one task on screen, which approximates focus, but there's no countdown or session tracking. If a timer with check-ins matters, FOCO is built around exactly that.

The bottom line

Goblin Tools and FOCO solve the same first five seconds of an ADHD stuck task almost identically: type it in, get small steps back.

Where they part ways is everything after that. Goblin Tools hands you the list and steps back. FOCO stays in the room.

If a list is all you've ever needed, Goblin Tools is free and instant. If you've had the list and still not done the task, that's the specific gap FOCO is built to close, and you can start free.
